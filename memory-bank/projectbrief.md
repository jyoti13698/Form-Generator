# Project Brief: Drag-and-Drop Form/Survey Builder

## Core Concept
A sophisticated UI application where users can drag form elements (input fields, dropdowns, checkboxes, etc.) onto a canvas to build custom forms and surveys. The final form schema is exported as JSON for further use.

## Key Requirements
- **Drag-and-Drop Interface**: Intuitive drag-and-drop functionality for form elements
- **Reordering**: Ability to reorder elements within the form
- **Preview Mode**: Real-time preview of the form as it's being built
- **JSON Export**: Export the complete form schema as downloadable JSON file
- **No Backend**: Pure frontend application with file download functionality

## Technical Stack
- **Frontend**: React with TypeScript
- **State Management**: Zustand (preferred) or Redux
- **Drag-and-Drop**: React DnD or dnd-kit library
- **Styling**: Modern CSS with professional design
- **Build Tool**: Vite or Create React App

## Success Criteria
- Smooth drag-and-drop experience
- Intuitive user interface that doesn't look AI-generated
- Professional, modern design
- Clean, maintainable code architecture
- Comprehensive form element support
- Reliable JSON schema generation

## Project Scope
This is a frontend-only application focused on demonstrating complex UI state management, drag-and-drop interactions, and schema generation capabilities. The emphasis is on creating a polished, professional tool that showcases advanced React patterns and user experience design.
